## Enfoque del Caso de Estudio

Este proyecto representa la base de mi especialización en **Desarrollo Front-End**, priorizando los fundamentos sólidos de la web (HTML semántico, CSS estructurado y JavaScript moderno) junto con la creación de interfaces reactivas en **Vue.js**.

### Aprendizajes y Ejecución

1. **Diseño Responsivo Real:** Cada vista del catálogo y detalle de producto fue pensada primero para dispositivos móviles (*Mobile-First*), escalando progresivamente hacia grillas multicolumna en escritorio.
2. **Componentes Reutilizables:** La organización visual de tarjetas de producto, filtros y estados vacíos se diseñó bajo principios de reutilización y consistencia.
